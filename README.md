# Doma

Ukrainian portfolio demo of a homewares store. Static HTML, CSS and JavaScript; publish repository root with GitHub Pages. No build step.

Catalog has six illustrative products, category selection, product details, quantities, editable cart, delivery choices and a simulated payment/order flow. Cart exists only for the current page session. Contact details stay in memory and are never transmitted or stored. No real payments, card collection, orders or deliveries.

Images generated with OpenAI ImageGen; not real merchandise. Prices and specifications are demo content. `products.png` is one 3×2 catalog contact sheet shown as individual CSS background panels.

Motion respects `prefers-reduced-motion`. Native dialogs support Escape, focus containment and keyboard controls. Production commerce would require a backend, real inventory, merchant details and a hosted payment provider.
